# Regressions

Two classic regression examples in R, with every step explained in code comments (in Polish).

## What's inside

| File | What it does |
|---|---|
| `Regresja liniowa.R` | **Linear regression** on the Wine Quality dataset – modelling wine density from fixed acidity |
| `Regresja Logistyczna Kobiety i Mężczyźni.R` | **Logistic regression** (GLM, binomial) – predicting a puffin's sex from its bill length, with the fitted sigmoid curve |
| `WineQT.csv` | Wine Quality data |
| `puffinbill.csv` | Puffin bill measurements |

## Stack

R · base graphics · `lm()` / `glm()`

## How to run

Open a script in RStudio, point `read.csv()` to the CSV file in this repo and run it line by line.
